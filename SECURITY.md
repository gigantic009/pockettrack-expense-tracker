# Security Policy

## Supported versions

Security fixes are currently targeted at the latest code on the `main` branch.

## Reporting a vulnerability

Please do not report exploitable security vulnerabilities in public issues.

Use GitHub's **Private vulnerability reporting** feature for this repository when it is enabled. If private reporting is unavailable, contact the repository owner privately through GitHub and include:

- A clear description of the affected component and impact.
- Steps to reproduce the issue or a minimal proof of concept.
- Any suggested mitigation.

Please avoid including real personal financial records, passwords, session cookies, API keys, or other secrets in a report.

## Scope and expectations

PocketTrack is a learning and portfolio project, not an audited financial service. Do not test against accounts or data you do not own. Reports will be reviewed as time permits; no formal response-time guarantee is made.
